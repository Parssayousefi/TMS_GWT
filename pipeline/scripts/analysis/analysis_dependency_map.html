Deconvolved time series

results/timeseries/*_timeseries_deconv.npy

Subjective questionnaires

data/{dataset}/{dataset}_subjective.csv

11ASC dimensions used in both correlation analyses.

Dataset configuration

configs/datasets/{dataset}.yaml

Defines tasks, control condition, subject list.

04_compute_phiid_revised.py

Computes redundancy/synergy/phi/phi_r matrices for each scan.

Output: results/phiid_matrices

05_group_average_workspace.py

Builds group-average matrices; identifies workspace mask.

Output: results/group_analysis/{dataset}/{task}

06_identify_gateways_broadcasters.py

Classifies workspace ROIs into gateway vs broadcaster.

Output includes *_gateway_broadcaster_summary.csv

06b_compare_conditions_gateways.py

Compares drug vs control roles using 06 control outputs.

Output: comparison_{drug}_vs_{control}

07_paired_statistical_testing.py

Paired ROI/network tests, correction, role-switch metrics.

Output: paired_stats_{drug}_vs_{control}

07b_network_based_statistics.py

NBS permutation analysis on phi_r edge changes.

Output: nbs_{drug}_vs_{control}

extract_role_switches.py

Extracts gateway<->broadcaster switch ROIs from 06b outputs.

Output: role_switches_{drug}_vs_{control}

extract_significant_role_switches.py

Keeps only switches supported by corrected stats from 07.

Output: significant_role_switches_{drug}_vs_{control}

08_analyze_regional_changes.py

Combines NBS outputs with workspace/gateway context.

Output: regional_effects_{drug}_vs_{control}

08_correlate_role_switches_subjective.py

Correlates 07 role-switch metrics with 11ASC scores.

Output: results/figures/{dataset}/role_switch_subjective_correlations

correlate_phir_subjective_effects.py

Correlates phi_r change in gateway/broadcaster/non-workspace ROIs with 11ASC.

Output: results/figures/{dataset}/phi_r_subjective_correlations

RUN_PAIRED_STATISTICS.md

Execution + interpretation guide for script 07 outputs.

No data output (documentation only).
